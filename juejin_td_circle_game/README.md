# 🏰 TD塔防游戏

一个基于Canvas 2D API开发的纯前端塔防游戏，具有丰富的塔类型、多样化的敌人和精心设计的30波挑战。

## 🎮 游戏特色

### 多样化的塔类型
- **箭塔** 🏹：基础远程攻击塔，平衡的攻击力和射程
- **炮塔** 💣：高伤害范围攻击，适合对付成群敌人
- **寒冰塔** ❄️：减速敌人，提供战术控制
- **毒塔** ☠️：持续伤害，削弱敌人生命值
- **英勇图腾** 🗲：增强周围塔的攻击力
- **急速信标** ⚡：提升周围塔的攻击速度
- **虚弱诅咒塔** 💀：降低敌人防御力
- **减速场发生器** 🌀：大范围减速敌人
- **银行塔** 🏦：持续产生金币收入

### 丰富的敌人种类
#### 基础敌人（第1-10波）
- **小鬼** 👹：基础敌人，血量适中
- **狼骑兵** 🐺：高速移动，难以瞄准
- **石头人** 🗿：高血量坦克型敌人
- **Boss** 👺：强力Boss，需要集中火力

#### 进阶敌人（第6-15波）
- **刺客** 🥷：极高速度，低血量，难以捕捉
- **重甲兵** 🛡️：高防御，移动缓慢，需要高伤害塔
- **飞行怪** 🦇：中等速度，特殊移动模式
- **治疗师** 🧙‍♀️：可治疗其他敌人，优先目标
- **狂战士** ⚔️：高攻击力，中等血量
- **巨人** 🧌：超高血量，移动极慢
- **幽灵** 👻：中等属性，特殊能力

#### 高级敌人（第16-25波）
- **龙** 🐉：强力飞行单位，高血量高奖励
- **死灵法师** 🧙‍♂️：魔法系敌人，中等血量
- **恶魔** 😈：高级战斗单位，全面强化
- **元素** 🔥：元素系强敌，特殊抗性
- **魔像** 🗿：超高防御构造体
- **吸血鬼** 🧛‍♂️：生命吸取能力，高速移动
- **巫妖** 💀：不死系法师，强力魔法单位

#### 终极敌人（第26-30波）
- **泰坦** ⚡：传说级巨型敌人，超高血量
- **终极Boss** 👹：最终挑战，最强敌人

### 游戏机制
- **30波敌人挑战**：精心设计的难度曲线，分为5个阶段
  - 第1-5波：基础教学阶段
  - 第6-10波：进阶阶段，引入新敌人
  - 第11-15波：中级挑战
  - 第16-20波：高级挑战
  - 第21-25波：专家级挑战
  - 第26-30波：终极挑战
- **塔升级系统**：每座塔可升级3次，提升各项属性
- **资源管理**：合理分配金币建造和升级防御塔
- **策略布局**：在有限的建造区域内规划最优防线
- **实时战斗**：流畅的实时战斗体验
- **渐进式难度**：从简单到复杂，适合不同水平的玩家

## 🎯 游戏操作

### 基础操作
- **建造塔**：点击绿色建造区域，选择塔类型
- **升级塔**：点击已建造的塔，选择升级
- **开始波次**：点击"开始下一波"按钮
- **暂停游戏**：点击暂停按钮

### 策略提示
1. **前期**：优先建造箭塔和炮塔，建立基础防线
2. **中期**：添加寒冰塔和毒塔，增强控制能力
3. **后期**：使用辅助塔增强整体防御，银行塔提供经济支持
4. **终极阶段**：合理搭配所有塔类型，应对强力敌人

## 🛠️ 技术架构

### 核心技术
- **HTML5 Canvas**：游戏渲染引擎
- **JavaScript ES6+**：游戏逻辑实现
- **CSS3**：界面样式设计

### 架构设计
- **模块化设计**：清晰的代码结构和命名空间
- **面向对象**：游戏实体采用类继承设计
- **事件驱动**：响应式的游戏交互
- **性能优化**：高效的渲染和更新机制

### 主要模块
- **TowerDefense.Engine**：游戏引擎核心
- **TowerDefense.Entities**：游戏实体（塔、敌人、弹道）
- **TowerDefense.Systems**：游戏系统（渲染、物理、AI）
- **TowerDefense.Data**：配置数据（塔配置、敌人配置、地图数据）
- **TowerDefense.Utils**：工具函数
- **TowerDefense.Assets**：资源管理

## 🔧 开发说明

### 添加新塔类型
1. 在 `TowerDefense.Data.TowerConfig` 中添加配置
2. 实现塔的特殊逻辑（如有需要）
3. 更新UI选择界面

### 添加新敌人
1. 在 `TowerDefense.Data.EnemyConfig` 中添加配置
2. 在 `TowerDefense.Data.WaveData` 中安排出现波次
3. 实现特殊能力（如有需要）

### 性能优化建议
- 使用对象池减少垃圾回收
- 优化渲染循环，避免不必要的重绘
- 合理使用requestAnimationFrame

## 🎯 游戏目标

成功抵御30波敌人的进攻，保护基地不被摧毁。每一波都会带来新的挑战：

- **生存挑战**：合理分配有限的资源
- **策略规划**：选择最优的塔类型和位置
- **时机把握**：在关键时刻升级防御
- **适应变化**：应对不同类型的敌人组合
