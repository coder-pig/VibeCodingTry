# TD塔防游戏需求文档

## 1. 项目概述

### 1.1 项目名称
TD塔防游戏（Tower Defense Circle Game）

### 1.2 项目描述
开发一款纯前端的塔防游戏，采用HTML5 Canvas技术实现，具有丰富的塔防策略元素和升级分支系统。

### 1.3 技术栈
- 前端：HTML5、CSS3、JavaScript (ES6+)
- 渲染：Canvas 2D API
- 部署：静态网页托管

## 2. 游戏设计

### 2.1 核心玩法
- 塔防类游戏，玩家通过建造和升级防御塔来阻止敌人通过地图
- 塔可升级至3级，3级时可选择两种不同的最终形态
- 共5波敌人，最后一波为Boss战

### 2.2 地图设计
- **布局**：左侧进怪口，蜿蜒曲折的循环路径
- **路径**：怪物沿固定方向移动的环形路线
- **建造区域**：路径两侧可建造防御塔的区域

## 3. 防御塔系统

### 3.1 升级机制
- **等级**：Lv1 → Lv2 → Lv3
- **升级费用**：指数级增长
  - Lv1 → Lv2：200金币
  - Lv2 → Lv3：400金币
- **分支选择**：Lv3时可选择两种不同的最终形态

### 3.2 攻击型塔

#### 3.2.1 箭塔 (Arrow Tower)
**定位**：单体、快速、廉价，前期主力

- **Lv1**：基础箭塔
  - 攻击力：20
  - 攻击速度：1.0秒/次
  - 射程：100像素
  - 建造费用：100金币

- **Lv2**：快速射击
  - 攻击速度提升30%（0.7秒/次）
  - 其他属性不变

- **Lv3分支**：
  - **A. 神射手哨塔**：射程+50%，攻击力+100%，30%暴击率
  - **B. 连弩塔**：同时攻击3个目标，适合清理杂兵

#### 3.2.2 炮塔 (Cannon Tower)
**定位**：群体、范围伤害(AOE)、慢速

- **Lv1**：基础炮塔
  - 攻击力：40
  - 攻击速度：2.0秒/次
  - 射程：120像素
  - 爆炸范围：30像素
  - 建造费用：150金币

- **Lv2**：重型炮弹
  - 爆炸范围+50%，攻击力+50%

- **Lv3分支**：
  - **A. 震荡炮**：附加0.5秒眩晕效果
  - **B. 导弹发射井**：射程+100%，攻速-25%，导弹追踪效果

#### 3.2.3 寒冰塔 (Ice Tower)
**定位**：减速、控制

- **Lv1**：单体减速
  - 减速效果：30%
  - 持续时间：3秒
  - 攻击速度：1.5秒/次
  - 建造费用：120金币

- **Lv2**：霜星 - 范围减速
  - 影响范围：50像素

- **Lv3分支**：
  - **A. 极寒冰锥**：减速效果提升至50%，15%概率冰冻1秒
  - **B. 碎冰诅咒**：被减速敌人受到物理伤害+20%

#### 3.2.4 毒塔 (Poison Tower)
**定位**：持续伤害(DoT)、穿甲

- **Lv1**：基础毒素
  - 毒素伤害：10/秒
  - 持续时间：5秒
  - 攻击速度：1.2秒/次
  - 建造费用：130金币

- **Lv2**：强效毒素
  - 毒素伤害提升至15/秒，持续时间7秒

- **Lv3分支**：
  - **A. 腐蚀毒雾**：降低敌人防御力25%
  - **B. 传染瘟疫**：被毒死的敌人爆炸传染周围敌人

### 3.3 辅助型塔

#### 3.3.1 英勇图腾
- **效果**：范围内攻击塔攻击力+15%
- **范围**：80像素
- **建造费用**：200金币

#### 3.3.2 急速信标
- **效果**：范围内攻击塔攻击速度+15%
- **范围**：80像素
- **建造费用**：200金币

#### 3.3.3 虚弱诅咒塔
- **效果**：降低范围内敌人防御力20%
- **范围**：60像素
- **建造费用**：180金币

#### 3.3.4 减速场发生器
- **效果**：范围内敌人移动速度-15%
- **范围**：100像素
- **建造费用**：160金币

### 3.4 功能型塔

#### 3.4.1 银行塔 (Bank Tower)
- **Lv1**：每秒产生2金币
- **Lv2**：每秒产生4金币
- **Lv3**：每秒产生6金币 + 波次结束利息机制
- **建造费用**：300金币

## 4. 敌人系统

### 4.1 基础敌人类型

#### 4.1.1 小鬼 (Grunt)
- **生命值**：50
- **移动速度**：60像素/秒
- **防御力**：0
- **奖励金币**：2
- **特点**：成群出现的炮灰单位

#### 4.1.2 狼骑兵 (Runner)
- **生命值**：30
- **移动速度**：120像素/秒
- **防御力**：0
- **奖励金币**：3
- **特点**：移动速度极快

#### 4.1.3 石头人 (Tank)
- **生命值**：200
- **移动速度**：30像素/秒
- **防御力**：10
- **奖励金币**：8
- **特点**：高血量高防御的肉盾

#### 4.1.4 萨满 (Healer)
- **生命值**：80
- **移动速度**：50像素/秒
- **防御力**：2
- **奖励金币**：6
- **特点**：治疗周围友方单位（5血/秒，范围50像素）

#### 4.1.5 潜行者 (Stealth)
- **生命值**：60
- **移动速度**：70像素/秒
- **防御力**：0
- **奖励金币**：5
- **特点**：免疫普通塔攻击，需要特殊检测

### 4.2 精英怪 (Elite)
- **属性**：基础属性×2
- **词缀系统**：随机获得1-2个特殊能力
  - **[加速]**：移动速度+50%
  - **[再生]**：每秒恢复5%最大生命值
  - **[护盾]**：抵挡3次攻击的护盾
  - **[召唤]**：死亡时召唤2只小鬼

### 4.3 Boss设计

#### 4.3.1 巨型憎恶 (第5波Boss)
- **总生命值**：1000
- **移动速度**：40像素/秒
- **防御力**：15
- **奖励金币**：100

**阶段机制**：
- **阶段一 (100%-50%血量)**：
  - 高防御力（25）
  - 技能：[战争践踏] - 每10秒眩晕周围所有塔1秒
  
- **阶段二 (50%-20%血量)**：
  - 防御力降低至10，移动速度+50%
  - 技能：[狂暴] - 免疫减速和眩晕
  
- **阶段三 (20%-0%血量)**：
  - 每损失5%血量召唤一波小鬼

## 5. 资源系统

### 5.1 金币系统

#### 5.1.1 获得方式
- **击杀敌人**：根据敌人类型获得不同金币
- **被动收入**：每秒1金币（可通过银行塔提升）
- **波次奖励**：完美防守（无漏怪）额外100金币
- **利息机制**：银行塔提供的额外收入

#### 5.1.2 消费方式
- 建造防御塔
- 升级防御塔
- 购买人口上限
- 卖塔返还75%建造费用

### 5.2 人口系统
- **初始人口**：5
- **购买费用**：
  - 第6个人口：50金币
  - 第7个人口：100金币
  - 第8个人口：200金币
  - 后续：费用翻倍增长

## 6. 胜负条件

### 6.1 胜利条件
- 成功防守5波敌人
- 在规定时间内击败最终Boss

### 6.2 失败条件
- 地图内同时存在超过25个敌人

## 7. 用户界面设计

### 7.1 游戏界面
- **主游戏区域**：Canvas渲染的游戏地图
- **资源显示**：当前金币、人口使用情况
- **塔建造面板**：可建造的塔类型和费用
- **波次信息**：当前波次、下一波预告
- **游戏控制**：暂停、加速、设置按钮

### 7.2 交互功能
- **攻击范围显示**：鼠标悬停或选中塔时显示攻击范围
- **塔升级界面**：点击塔显示升级选项和分支选择
- **下一波预告**：显示即将到来的敌人类型，给予10-15秒准备时间

## 8. 技术实现要求

### 8.1 性能要求
- 游戏帧率稳定在60FPS
- 支持同屏最多50个游戏对象
- 响应式设计，适配不同屏幕尺寸

### 8.2 兼容性要求
- 支持现代浏览器（Chrome 80+、Firefox 75+、Safari 13+）
- 移动端基础支持

### 8.3 代码规范
- 使用ES6+语法
- 模块化开发
- 添加详细的中文注释
- 遵循统一的代码风格
